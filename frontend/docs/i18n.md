# Internationalization (i18n)

Spanish (`es`) is the default language. English (`en`) is also supported.

## Stack

- [i18next](https://www.i18next.com/) + [react-i18next](https://react.i18next.com/)
- Locale persisted in `localStorage` via Zustand (`store/localeStore.ts`)

## Structure

```
src/locales/
├── types.ts          # SupportedLocale, DEFAULT_LOCALE = 'es'
├── es/
│   ├── common.ts     # Shared strings
│   ├── auth.ts
│   ├── home.ts
│   ├── app.ts
│   ├── legal.ts
│   └── index.ts
└── en/               # Mirror es/ structure
```

## Usage in components

```tsx
import { useTranslation } from 'react-i18next'

function MyPage() {
  const { t } = useTranslation()
  return <h1>{t('auth.signInTitle')}</h1>
}
```

With interpolation:

```tsx
t('auth.signInAfterReturn', { url: '/profile' })
```

## Change language

Use the floating switcher (top-right) or programmatically:

```tsx
import { useLocaleStore } from '@store'

const setLocale = useLocaleStore((s) => s.setLocale)
setLocale('en')
```

## Add a new language

1. Copy `src/locales/es/` → `src/locales/<code>/`
2. Translate all files
3. Register in `locales/types.ts` → `SUPPORTED_LOCALES`
4. Add to `lib/i18n/config.ts` resources

## Add translations for a feature

1. Add `auth.ts` keys in both `es/` and `en/`
2. Export from each `index.ts`
3. Use `t('auth.myKey')` in feature pages

TypeScript autocomplete works via `src/types/i18next.d.ts` (typed from Spanish resources).
